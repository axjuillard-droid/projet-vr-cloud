# Rechercher avant de créer

## Objectif
Réutiliser une solution gratuite adaptée lorsque cela réduit le travail sans nuire à la compréhension, à la compatibilité ou à la publication du projet.

## Méthode
1. Définir le besoin immédiat et ses contraintes : plateforme, version, qualité attendue, modification nécessaire.
2. Consulter `docs/RESOURCES.md` depuis la racine du projet. Réutiliser une évaluation encore pertinente ; vérifier de nouveau les informations susceptibles d’avoir changé.
3. Effectuer une recherche courte et ciblée. Privilégier les sources officielles, les dépôts d’origine et les pages de licence. Quelques candidats crédibles suffisent ; approfondir seulement si un obstacle le justifie.
4. Vérifier gratuité, licence, attribution, redistribution dans un GitHub public, compatibilité et coût d’adaptation. Pour la 3D, considérer aussi complexité géométrique, matériaux, échelle et utilisation VR.
5. Consigner une conclusion brève dans `docs/RESOURCES.md` : réutiliser, adapter ou créer, avec les sources et la raison. Une licence inconnue ne permet pas de considérer l’élément comme réutilisable.
6. Continuer dans le périmètre autorisé. La recherche ne constitue pas une autorisation d’achat, de création de compte ou d’installation.

## Discipline
- Ne pas rechercher chaque petite ligne de code indépendamment : évaluer le composant ou la fonctionnalité utile.
- Si aucun candidat ne convient après cette recherche bornée, expliquer pourquoi puis créer seulement ce qui est nécessaire.
- Ne pas confondre gratuité du développement et gratuité d’exploitation d’un service externe.
- Préserver les mentions de licence dans les éléments repris et consigner leur provenance.
- Ce fichier est chargé via `AGENTS.md` ; ne pas prétendre qu’un plugin ou un connecteur a été installé.
