## Objectif de livraison

Prototype Unity pour Meta Quest, exécutable PC, documentation technique, guide utilisateur et démonstration finale. Le dépôt devra permettre de comprendre les choix techniques et, à terme, de reproduire l’installation et la compilation.

Le projet de test ConnectionTest utilise Unity 6000.0.58f2. La lecture et la création d’un objet Unity par MCP HTTP, ainsi que le pilotage Blender par Python en arrière-plan, ont été vérifiés ; voir docs/TOOLING.md. Aucun build PC/Quest validé ni automatisation périodique à ce stade.
