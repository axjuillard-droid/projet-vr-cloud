# Refroidissement du data center V2 — 10 novembre 2026

Depuis le point de vue sur la centrale, viser et ouvrir la vanne de démonstration. Le liquide chaud est représenté par les repères orange jusqu’à l’échangeur. La chaleur est transmise à un circuit de rejet séparé et évacuée par un aéroréfrigérant sec. Les repères bleus repartent ensuite vers les baies. Les mouvements sont accélérés pour la visite. La scène n’est pas une simulation hydraulique.

Le test D3D11 vérifie l’accès dans l’ordre, la rotation de la vanne, la marche jusqu’à l’échangeur, le passage de la chaleur avant le premier retour et la validation du point d’observation.
