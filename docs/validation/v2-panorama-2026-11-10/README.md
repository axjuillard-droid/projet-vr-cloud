# Panorama depuis le belvédère — 10 novembre 2026

Quatre rangées latérales se prolongent le long de la rampe avec 24 baies supplémentaires. Le hall modélisé compte 66 baies, dont la baie école. Le plafond, les poutres, les chemins de câbles et les luminaires se prolongent aussi vers le belvédère. Les nouveaux voyants suivent les paliers existants.
