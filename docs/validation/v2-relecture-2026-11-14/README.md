# Vérification de l’original au stockage

Le client est orienté vers l’allée. Après l’écriture dans la banque B, le joueur demande une relecture et l’image suit la liaison de retour. L’écran montre l’original 96 × 64 et l’aperçu CPU 24 × 16. Une sélection de l’aperçu explique l’écart. La confirmation de l’original ouvre le belvédère.

Le test Windows D3D11 vérifie le départ de la relecture depuis la banque, le refus du double clic, l’identité des deux images, le refus de l’aperçu et la confirmation de l’original. Le scénario de stockage conserve les données en mémoire pour la visite. Un essai humain et un essai Quest restent à effectuer.
