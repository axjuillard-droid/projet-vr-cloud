# Pompe d’appoint et rivière V2

Le test Windows vérifie l’arrêt initial, les deux niveaux de pompage et le bilan prélèvement, évaporation et restitution. En été sec, le pompage fort rétrécit la surface et stresse les poissons. Une réduction précoce permet leur récupération. Un prélèvement prolongé entraîne trois pertes dans le scénario testé. L’arrêt coupe les flux et élargit de nouveau la surface sans effacer les pertes.
