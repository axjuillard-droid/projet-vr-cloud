# Mission météo et refroidissement

Le joueur stabilise le service dans trois conditions. Le froid permet de servir quatre rangées avec le rejet sec. Le temps tempéré demande le débit réduit de la pompe d’appoint. En canicule, le débit fort permet encore d’en servir quatre, mais le prélèvement exerce une pression sur la rivière. Deux rangées prioritaires et le débit réduit permettent de terminer la mission sans perte.

Le test Windows Direct3D 11 valide les trois scénarios, puis vérifie séparément que le surpompage prolongé cause des pertes persistantes. La manette de pompe représente le niveau sélectionné par les commandes du pupitre. Les capacités, seuils et durées sont des paramètres pédagogiques. Le HUD est absent des captures caméra. L’essai humain et le casque restent à évaluer.
