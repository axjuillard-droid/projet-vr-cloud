## Publication des preuves

Avant publication GitHub le 05/10/2026, les chemins et identifiants propres à la machine ont été remplacés par `<PROJECT_ROOT>`, `<USER_HOME>`, `<HOST>` et `<LOCAL_IP_…>`. Les résultats, dates, versions, GPU, erreurs, compteurs et empreintes de build restent inchangés. Les originaux sont conservés localement sous `tmp/unity/publication-originals/`, ignoré par Git.

Les captures sont des images réelles de l'éditeur ou du player, selon le dossier. Elles ne représentent pas un essai Quest lorsque celui-ci n'a pas eu lieu. Les binaries de build et les sessions du pont MCP ne sont pas distribués ici.
